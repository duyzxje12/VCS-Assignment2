# Product Backlog

- **US-01**: As a user, I want to log in with email and password, so that I can access my account.
- **US-02**: As a guest, I want to register a new account, so that I can use the app.
- **US-03**: As an user, I want to reset my account, so that I can change password in case I forget my password.
- **US-04**: As an administrator, I want to see the account list, so that I can handle and manage the accounts.
